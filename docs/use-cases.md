# use-cases
# Casos de Uso


## Carteira (Wallet)

UC001 - O usuário pode criar uma Wallet.

UC002 - O usuário pode listar todas as Wallets.

UC003 - O usuário pode alterar o nome, descrição e status de uma Wallet.

UC004 - O usuário pode excluir uma Wallet desde que não existam Reserves associadas.

---

## Reserva (Reserve)

UC005 - O usuário pode criar uma Reserve.

UC006 - O usuário pode listar as Reserves.

UC007 - O usuário pode alterar o nome, descrição e status de uma Reserve.

UC008 - O usuário pode excluir uma Reserve desde que não existam Goals associados.

---

## Objetivo (Goal)

UC009 - O usuário pode criar um Goal.

UC010 - O usuário pode listar os Goals.

UC011 - O usuário pode alterar:

* name
* description
* initial_amount
* target_amount
* target_date
* priority
* status

UC012 - O usuário pode excluir um Goal desde que não existam Investment Transactions associadas.

---

## Tipo de Investimento (Investiment Type)

UC013 - O usuário pode cadastrar um tipo de investimento.

UC014 - O usuário pode listar os tipos de investimento.

UC015 - O usuário pode alterar nome e descrição.

UC016 - O usuário pode excluir um tipo de investimento que não esteja sendo utilizado por nenhuma Investment Transaction.

---

## Movimentações (Investment Transaction)

UC017 - O usuário pode registrar uma Investment Transaction.

UC018 - O usuário pode consultar as Investment Transactions.

UC019 - O usuário pode alterar os dados de uma Investment Transaction.

UC020 - O usuário pode excluir uma Investment Transaction.

---

## Reports

UC021 - O usuário pode consultar o saldo de um Goal.

UC022 -  O usuário pode consultar o saldo de uma Reserve.

UC023 - O usuário pode consultar o saldo de uma Wallet.
