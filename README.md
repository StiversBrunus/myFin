# 💰 MyFin

### Personal Finance & Investment Management

*A personal project built to manage investments, wealth, income, expenses and financial goals.*

This is my personal project.

I'm building an application to manage my investments and personal finances. The project is being developed step by step, starting with the **Investment Management** module. In the future, it will also include a complete **Personal Finance Management** module.

## 📂 Current Repository Structure

At the moment, this repository includes:

- 🗄️ Complete PostgreSQL database schema
- 📐 Conceptual and logical database models
- 🖼️ Entity Relationship Diagram (ERD)
- 📚 Data Dictionary
- 📋 Business Rules
- ✅ Use Cases
- ✔️ Validation Rules
- 🧪 Manual Database Tests
- 📄 SQL scripts
- 📖 Project documentation
- 🚧 Initial application architecture
